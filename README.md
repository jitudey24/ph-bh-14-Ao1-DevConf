# DevConference 2026 — Event Landing Page

A developer conference landing-page concept for a three-day event bringing together engineers, founders, and builders.

## Features
- Conference navigation for Speakers, Schedule, Tracks, Venue, and Blog
- Hero section with event introduction
- Register Now call to action
- Conference-focused visual layout
- Font Awesome icon support

## Technologies
- HTML5
- CSS3
- Google Fonts
- Font Awesome

## Run Locally
1. Clone this repository.
2. Keep the `assets` folder and stylesheet in the project directory.
3. Open `index.html` in your browser.

## Project Purpose
A Programming Hero assignment for practicing event-page structure, navigation, and responsive styling.
